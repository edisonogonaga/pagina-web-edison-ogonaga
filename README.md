# 🌐 Página Web Personal — Edison Ogonaga

Página web personal desarrollada como actividad extracurricular para la **Escuela Politécnica Nacional** (EPN).

## 📋 Descripción

Sitio web moderno y responsive que presenta mi perfil como estudiante de **Ingeniería en Computación**. Incluye información sobre mis habilidades, proyectos, intereses y datos de contacto.

## 📁 Estructura del proyecto

```
pagina-web-edison-ogonaga/
│
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos del sitio
├── js/

├── assets/
│   ├── images/         # Imágenes (foto de perfil, etc.)
│   └── icons/          # Iconos adicionales
└── README.md           # Este archivo
```
